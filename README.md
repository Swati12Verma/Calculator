# 🧮 Calculator

## 📌 About the Project
This is a simple and responsive Calculator Web Application developed using HTML, CSS, and JavaScript. It performs basic mathematical operations with a clean and user-friendly interface.

## 🚀 Features
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Percentage (%)
- AC button to clear all input
- DEL button to delete the last entered value
- Responsive design
- User-friendly interface

## 🛠️ Technologies Used
- **HTML5** – Structure of the calculator
- **CSS3** – Styling and layout
- **JavaScript** – Functionality and calculations
